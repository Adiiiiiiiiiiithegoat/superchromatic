# E-Cell NITK Tech Recruitment 2026 — Task 3: Frontend Development
Deadline: 20 October 2026, 11:59 PM IST

## Task: Build an Image-Based Theming Engine
Build an interactive theming tool that allows users to upload a wallpaper, extract its colors, and generate a visually consistent theme for a web interface. Users should be able to experiment with different color palettes, presets, and visual adjustments while seeing the changes reflected in a live preview.

## Requirements
- **Image Upload & Color Extraction:** Allow users to upload an image and extract a representative color palette from it. Display the extracted colors and allow users to select the colors they want to use in their theme.
- **Theme Presets:** Provide a set of predefined theme presets or moods, such as Minimal, Vibrant, Warm, Cool, and Glass. These should modify how the extracted colors are used throughout the interface.
- **Visual Adjustments:** Provide interactive controls or dials to adjust properties such as saturation, brightness, contrast, background blur, and overlay opacity. Changes should be reflected in real time.
- **Live Theme Preview:** Build a testing page alongside the customization controls that demonstrates how the generated theme looks when applied to actual UI components.
- **Themed UI Components:** The preview should contain:
  - Primary heading and secondary text.
  - Main background and card background.
  - Primary card text and secondary text.
  - Primary and secondary buttons.
  - Input fields, badges, and other common UI elements.
  - A sample layout containing cards, sections, and interactive elements to demonstrate the overall theme.
- **Theme Consistency:** Changing the selected colors or adjustments updates all relevant components consistently rather than styling each component independently.
- **Responsive Design:** Works well across screen sizes, intuitive on desktop and mobile.

## Deliverables
- GitHub repository containing the source code.
- A walkthrough video explaining everything.
- A brief README explaining the implementation, color extraction approach, theme generation logic, and design decisions.

## Bonus
- Multiple palette extraction strategies, or letting users select individual colors from the uploaded image.
- Accessibility-aware color selection to maintain readable text and sufficient contrast.
- Smooth transitions and micro-animations when changing themes.
